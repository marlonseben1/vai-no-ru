Olá! Esse mini projeto é uma ideia que tive para resolver um problema real da faculdade.

Esquecer de preencher o formulário do restaurante universitário (RU) e pagar o dobro por cada refeição!

O objetivo desse projeto é automatizar o processo de preenchimento do formulário. 

Dessa forma, você preenche 1 vez na semana ou no mês (como preferir) e o autofiller cuida do resto!
